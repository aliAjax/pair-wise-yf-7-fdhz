# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出PNG预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 付印校次闸门

- 右侧「付印校次」面板点击**送校付印**，首次送校需登记校对人、错字格（点格子标记并逐格填正字）和返修说明。
- 存在**超量字模**、**空作品名**或**错字格未登记正字**时整次拒绝，弹窗列出原因，草稿与原版面保持不变。
- 任一**落字**或**字模数量**改动（含清空版面、删字模、换纸型、载入草稿）后，已有校样立即恢复「待校」并生成新版本；旧版本只读，可在校次列表中回看。
- 同一格连续返修两次后，再次无错通过时必须更换校对人，否则闸门拒绝。
- 校次列表、版面错字格占用提示与全部数据保存在浏览器 localStorage，并通过 storage 事件跨标签页同步，刷新后保留。
