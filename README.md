# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出PNG预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 付印校次闸门

右栏「付印校次」在草稿定稿后提供送校登记：

- 首次送校需登记校对人；点版面格标出错字格并逐格（或批量）登记，有错字格时必须填写返修说明。
- 提交时整次校验，任一不满足则拒绝且**草稿与原版面不变、不写校次、不升版本**：仍有超量字模、作品名为空、存在标了但未登记的错字格、未填校对人、有错字格但缺返修说明。
- 任一落字增删替换、字模数量增减（含删字模/载入草稿/换纸裁切）后，已有校样立即恢复待校，自动生成新版本（v1、v2…），旧版本校次只读保留。
- 同一格连续返修两次后，再申请通过必须更换校对人，原校对人会被拒绝。
- 校次列表与待返修占用提示（含连续返修次数、换人提醒）随状态保存在浏览器 localStorage，刷新与多标签页（storage 同步）后保留。
